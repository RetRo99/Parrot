# Third-Party Reader Fonts

The Android reader bundles these open-source fonts for the font-family picker:

- Droid Sans, from Android Open Source Project, Apache License 2.0.
- Atkinson Hyperlegible, from Google Fonts, SIL Open Font License 1.1.
- Literata, from Google Fonts, SIL Open Font License 1.1.
- Merriweather, from Google Fonts, SIL Open Font License 1.1.
- Source Serif 4, from Google Fonts, SIL Open Font License 1.1.
- Noto Sans, from Google Fonts, SIL Open Font License 1.1.
- Noto Serif, from Google Fonts, SIL Open Font License 1.1.

Font files live under `feature/reader/ui/src/androidMain/assets/reader-fonts/bundled`.

License texts are kept in `docs/third_party_fonts`.

## App UI fonts

The app theme (Ember) bundles static instances of these fonts for titles and UI text:

- Fraunces, from Google Fonts, SIL Open Font License 1.1 (`docs/third_party_fonts/OFL-Fraunces.txt`).
- Figtree, from Google Fonts, SIL Open Font License 1.1 (`docs/third_party_fonts/OFL-Figtree.txt`).

Font files live under `base-ui/src/commonMain/composeResources/font`.
