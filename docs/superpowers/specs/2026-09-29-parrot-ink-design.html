Parrot InkDesign system · v2 draft
Parrot for Storyteller · Android & iOS

Made from ink. Readable on any screen.

Parrot Ink is one system with two treatments. On e-ink it uses grayscale, strokes and type, with no motion. On color screens it uses the same layout and type, plus book covers, filled surfaces and motion. The switch above shows the component kit in either treatment.

Foundations

Six rules for the panel

E-ink redraws slowly, ghosts after partial refreshes and shows 16 levels of gray. Every rule here follows from those limits. When a rule works on e-ink, it also makes the app calmer on color screens.

Invert, don't tintSelected tabs, chips and switches go solid black with white text. A light-gray tint is invisible on many panels.
Strokes, not shadowsSurfaces are separated by 2 dp outlines and 1 dp rules. No elevation, blur or translucency.
Four grays, no morePaper, wash, rule, ink-2 and ink. Each snaps to a real panel level, so the display never has to dither a gray.
Nothing movesNo ripples, fades or animated progress. State changes in one frame, which is one refresh.
Turn pagesLists and the reader move by full pages with volume keys or edge taps. Smooth scroll is the fallback on color screens.
48 dp targetsE-ink touch layers are imprecise. Main controls are 48 dp or larger, and play/pause is 72 dp.
Color

The 16-level ramp

A 4-bit e-ink panel can show 16 grays, spaced 0x11 apart. Parrot uses five of them, marked with a ring. The accent is Parrot green on color screens. On e-ink it becomes ink.

paper#FFF · background, surface
wash#EEE · readaloud highlight, code
rule#BBB · dividers, outlineVariant
ink-2#555 · secondary text
ink#111 · text, outline, primary
parrot#2E6B52 · accent, color only

Error states use shape and words rather than red: a dashed outline, an × glyph and a sentence that says what to do next. On e-ink, red and black look the same.

Color screens

On a regular Android phone

Most people read on a normal phone, so color screens get a design of their own instead of the e-ink design with green added. Both share the same typefaces, layout and components. On a color screen those components get book covers, depth and motion.

Covers firstThe library opens as a cover grid. Each cover's color tints its own Continue card, book page, player and mini player.
Layers, not linesCards and panels are soft filled surfaces in three tones. Outlines are only for text fields.
Motion that explainsA cover grows from the grid into the book page and then into the player. Back gestures preview the screen underneath. Animation follows the system speed setting.
Matches your phoneAn optional "Match wallpaper colors" setting on Android 12 and later. The app draws behind the status and navigation bars.
You can feel itLight haptic ticks on play/pause, skip, seeking by chapter and adding a bookmark.
Uses big screensOn tablets and unfolded phones, a navigation rail on the side and the book next to the library.

Behavior

Motion & refresh

Do

  • Swap state in one frame: selected, pressed, playing.
  • Update the player clock once a second. Update the reader progress bar once per segment.
  • Trigger a full refresh after every 6 page turns to clear ghosting. Make the interval a setting.
  • Use a wash background plus an underline for the readaloud sentence.

Don't

  • Ripples, crossfades, shimmer placeholders, animated spinners.
  • Tinted containers such as surfaceVariant.copy(alpha = 0.45f).
  • Blurred color from DominantColor behind covers.
  • Text lighter than ink-2 (#555) or thinner than weight 400.
Implementation

Compose mapping

Parrot Ink replaces the three schemes in ParrotTheme.kt. E-ink gets a pure grayscale scheme. Color screens get softly tinted surface tones, the green accent, larger corners and optional wallpaper colors.

// base-ui · ParrotTheme.kt
@Composable
fun ParrotTheme(
    darkTheme: Boolean = isSystemInDarkTheme(),
    eink: Boolean = false,
    matchWallpaper: Boolean = false,
    content: @Composable () -> Unit,
) {
    val colorScheme = when {
        eink -> InkEinkColorScheme
        matchWallpaper -> dynamicColorScheme(darkTheme) ?: parrotColorScheme(darkTheme)
        else -> parrotColorScheme(darkTheme)
    }
    CompositionLocalProvider(
        LocalEink provides eink,
        LocalIndication provides if (eink) NoIndication else ripple(),
    ) {
        MaterialTheme(
            colorScheme = colorScheme,
            typography = InkTypography, // Literata · Atkinson · Plex Mono
            shapes = if (eink) InkShapes else ColorShapes,
            content = content,
        )
    }
}

Existing ParrotTopBar, SettingsSection and SettingsRow keep their APIs. Only their styling changes: cards are outlined on e-ink and filled surface tones on color screens.
