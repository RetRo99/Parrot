## Steps and results

1. On the first app start after the update, the original Open Last Book setting was ON and the known “Server unavailable or not authenticated” prompt appeared. Tapped Close only; did not retry or alter credentials/server/book state. This is the previously recorded case-424 fixture blocker, not a case-436 persistence failure.
2. Opened App Settings and changed Open Last Book OFF, Show Continue Reading OFF, File Logging ON, then Only Log Crashes ON. The installed build displayed the expected values.
3. Local debug output showed one `app_setting_toggle_attempted` followed by the existing setting-specific success event for each change. Each operation had a correlated `started` and `terminal/succeeded` diagnostic breadcrumb. All eight emitted events had `is_retry=false`; no toggle failure/cancellation event or exception was observed.
4. Force-stopped Parrot and relaunched `.android.MainActivity`. Books opened without the saved-book route/auth prompt. The existing filtered-empty state remained. App Settings then showed Open Last Book OFF, Show Continue Reading OFF, File Logging ON, and Only Log Crashes ON, confirming all four values persisted across restart.
5. Restored the original preferences in dependency-safe order: Only Log Crashes OFF, File Logging OFF, then Open Last Book ON and Show Continue Reading ON. Verified all final states. No second restart was done after restoring Open Last Book ON.
6. Cleared the temporary diagnostic file through Clear Logs. Local output showed one clear attempt/success pair with correlated breadcrumbs; both active and rotated files were absent afterward. No app data was cleared.

## Additional instrumentation finding

During the initial post-update startup/route transition, two sanitized `HttpException` records were emitted by the local debug provider from Coil image-fetch failures. No toggle operation failed, and the app did not crash. Source audit confirms `base-ui/.../CoilImage.kt` calls `analytics.logException` for every `AsyncImagePainter.State.Error`, without filtering expected HTTP/network/cancellation failures or deduplicating repeated image requests. This independent diagnostics-noise gap was recorded as QA-BUG-0075 before remediation. Raw logs, exception messages, cache keys, and image URLs were not retained; Crashlytics delivery is unverified.

Evidence was inspected from PID-scoped ADB output. Local DebugAnalyticsManager output is not Firebase delivery evidence.
