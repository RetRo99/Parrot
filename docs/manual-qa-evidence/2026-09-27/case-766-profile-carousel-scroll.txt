## Functional result

1. Horizontally swipe the profile row from right to left. The trailing Add Profile tile becomes visible; existing duplicate ordinal markers remain distinct. The active marker moves with the same active profile, and the screen's vertical Settings content remains in place.
2. Tap the newly visible Add Profile tile. Its dialog opens. Cancel it; no profile is created and the active profile remains unchanged.
3. Swipe the row back to the start. The original profile tile returns to view, Add Profile moves outside the initial viewport again, and the same active profile remains selected. No unrelated setting or screen action is triggered.
